# Smart Text Analytics Pipeline - Hackathon Submission

## 🎯 Project Overview

**AWS Engineering Day Hackathon 2024**

A lightweight, intelligent pipeline that transforms unstructured open-ended survey responses into actionable business insights using AWS AI/ML services.

### Problem Solved
- **Input**: Raw survey responses like "The music was great but the lines were too long"
- **Output**: Structured topics ("Music Quality", "Wait Times") with sentiment analysis and PII safety

## 🏗️ Architecture

### Core Components
1. **PII Detection & Redaction**: Amazon Comprehend (with regex fallback)
2. **Text Embeddings**: Bedrock Titan Text Embeddings v2
3. **Topic Labeling**: Bedrock Claude Sonnet 
4. **Sentiment Analysis**: Amazon Comprehend (with keyword fallback)
5. **Clustering**: UMAP + HDBSCAN (local processing)

### Smart Fallback System
- **Service Detection**: Upfront AWS service availability testing
- **Graceful Degradation**: Automatic fallback to local algorithms when AWS services unavailable
- **Demo-Ready**: Works regardless of permission constraints

## ✨ Key Features

### 🔒 Security & Privacy
- **PII Detection**: Automatically identifies and redacts emails, phone numbers, etc.
- **Clean/Raw Separation**: Maintains original data while processing sanitized versions
- **Compliance Ready**: Built for handling sensitive survey data

### 🧠 Intelligence
- **Multi-Service Architecture**: Different AWS services for different use cases
- **Contextual Topic Labels**: 2-3 word labels generated by Claude Sonnet
- **Sentiment Analysis**: Both response-level and topic-level insights
- **Robust Clustering**: UMAP + HDBSCAN for meaningful topic discovery

### ⚡ Performance
- **Processing Speed**: ~12 minutes for 1,000 responses
- **Cost Efficient**: Smart batching and rate limiting
- **Scalable Design**: Ready for production deployment with Step Functions
